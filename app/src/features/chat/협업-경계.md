# 채팅 협업 경계

- `viewTypes.ts`는 화면과 컨테이너가 공유하는 계약이다. 변경이 필요하면 먼저 상위 담당자와 협의한다.
- 화면 담당자는 `ui/ChatListView.tsx`, `ui/ChatRoomView.tsx`, `ui/ChatOpenSheet.tsx`와 필요한 `ui/` 하위 파일을 작성한다.
- 화면은 props와 콜백만 사용하며 API, 세션, 라우터, 저장 상태를 직접 연결하지 않는다.
- 런타임 담당자는 `ui/` 밖의 채팅 데이터와 상태를 작성한다. 라우트와 기존 화면 연결은 별도 통합 단계에서 처리한다.
- `status`는 표시용이며 종료 사유를 드러내지 않는다. 완료 매칭에서는 `canMessage`와 `canOpen`을 모두 false로 표시한다.
- 번역은 `content`의 원문, 번역문, 원문 언어를 유지한다. 불확실한 전송과 열기는 성공으로 표시하거나 자동 재전송하지 않는다.
