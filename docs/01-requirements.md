## MVP (본선 데모 · 11/29)

서울에 사는 한국인 메이트가 만든 **비밀지도**를 따라 일본인 여행자가 취향에 맞는 서울 여행을 하는 **모바일 앱(iOS·Android)**을 구현한다. 매칭 → 비밀지도 탐방 → 채팅 → 앨범까지 한 번의 여행 흐름을 끝까지 시연할 수 있어야 한다.

### 1. 계정/역할 정의

| 역할 | 설명 | 권한 |
| --- | --- | --- |
| 비로그인 | 앱을 처음 연 사용자 | 국적 선택, 회원가입, 로그인만 가능 |
| 여행자(TRAVELER) | 국적을 일본으로 선택한 사용자. 앱 화면은 일본어 | 지도 고르기(고르면 바로 매칭), 매칭 끊기, 방문 인증, 채팅 열기, 여행 완료·앨범, 후기 작성, 신고·차단(언제든). 매칭 칸 무료 5칸 |
| 메이트(MATE) | 국적을 한국으로 선택한 사용자. 앱 화면은 한국어 | 비밀지도·스팟 생성·수정, 방문 기록 확인, 리액션·댓글, 채팅, 앨범 보기, 후기 작성, 신고·차단(언제든). 매칭 수락·거절 단계는 없고, 매칭 끊기(사유 선택)는 가능 |
| 어드민(ADMIN) | 운영자 | 신고 내역 확인·처리 (MVP는 DB에서 직접 처리, 화면은 선택 기능) |

### 2. 필수 기능 (MVP)

#### 회원/온보딩

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-01 | 국적 선택 | 앱 첫 화면에서 일본 / 한국을 선택한다. 선택에 따라 화면 언어(일본어 / 한국어)와 가입 후 화면이 나뉜다 | 선택값 저장, 이후 모든 화면이 해당 언어로 표시. 일본 = 여행자, 한국 = 메이트로 역할 자동 지정 |
| F-02 | 회원가입 | 이메일·비밀번호(최소 8자)·약관 동의 | 비밀번호 암호화 저장, 201 / 이메일 중복 409, 약관 미동의 400 |
| F-03 | 로그인 | 이메일·비밀번호로 로그인하고 토큰을 발급받는다 | 로그인 성공 시 accessToken 발급, 앱 재실행 시 로그인 유지 / 비밀번호 불일치 401 |

| F-05 | 연령 제한 | 만 18세 이상만 가입할 수 있다 | 출생연도 기준 만 18세 미만이면 가입 불가 400 |

| F-07 | 취향 선택 | 여행자·메이트 공통 화면. 대분류 → 세부 순서로 고른다(예: 카페 → 조용한 카페). 여행자는 "여행 취향", 메이트는 "추천할 수 있는 취향·동네"로 문구만 다르다 | 1~10개 선택 가능, 0개 또는 11개 이상 400. 같은 취향 목록을 언어별 이름으로 표시 |

| F-09 | 여행 일정 입력 | 여행자가 방한 시작일·종료일을 입력한다 | 종료일이 시작일보다 빠르면 400, 지난 날짜 400. 일정이 없으면 메이트 찾기를 이용할 수 없음 |

#### 매칭

| ID | 기능 | 설명 | 완료 기준 |
| --- | --- | --- | --- |
| F-15 | 메이트 찾기 | 매칭 조건(성별·연령대)을 통과한 메이트를 **인원 제한 없이 목록으로** 보여 준다. 정렬: ① 취향 일치순(기본, 겹치는 취향 수) ② 핀이 많은 지도 순 ③ 최근 업데이트 순 ④ 인기순(코스로 선택된 횟수). 필터: 핀 개수 범위(5개 ~ 20개 이상) | 차단한 상대, 정원(10명)이 찬 메이트, F-13 조건 미달 메이트, 이미 진행 중인 매칭 상대는 제외. 20명씩 나눠 불러오기. 핀 개수는 **지도 하나 기준**(카드·정렬은 가장 큰 지도, 필터는 범위 안에 드는 지도가 하나라도 있으면 표시) |
| F-16 | 메이트 카드 | 닉네임·성별·연령대·겹치는 취향(공통 n)·핀 수(가장 큰 지도)·최근 업데이트·선택된 횟수를 보여 준다. 지도 내용은 이 단계에서 보이지 않는다 | 카드 응답에 지도 이름·캡션·스팟 정보 미포함 |
| F-17 | 매칭 신청 | 목록에서 1명을 고르면 바로 매칭된다. 메이트는 거절할 수 없다. 매칭 칸 1칸을 사용한다. 하루 신청 횟수 제한은 없다 | 성공 201, 빈 칸이 없으면 409, 메이트 정원 초과 409, 목록 조건(F-15)을 통과하지 못한 메이트 신청 400 |
| F-18 | 매칭 칸 | 여행자는 **무료로 5칸**을 쓴다. 칸 수만큼 서로 다른 메이트와 동시에 매칭할 수 있어, 날마다 다른 코스(예: 1일차 카페, 2일차 관광지)로 여행하고 더 많은 한국인 친구를 사귈 수 있다. 칸은 매칭 취소·종료·여행 완료 시 다시 비워진다 | 사용 중인 칸 = 진행 중인 매칭 수, 최대 5. 결제는 MVP에서 구현하지 않음 |
| F-19 | 지도 공개 | 매칭되면 메이트의 지도 목록이 열린다. 각 지도의 캡션과 공개 스팟 2곳만 볼 수 있다 | 공개 스팟 외 스팟의 상세 정보는 응답에 미포함 |
| F-20 | 코스 지도 선택 | 여행자가 지도 하나를 코스로 고르면 그 지도의 스팟 전체가 열리고 여행이 시작된다. 이때 채팅에 필요한 인증 수(코스 스팟 수의 50%, 소수점 올림)가 확정된다 | 공개 조건(F-13) 미달 지도 선택 불가, 코스 선택 후 해당 지도 스팟 전체 조회 가능. 필요 인증 수는 이후 메이트가 스팟을 추가해도 바뀌지 않음 |
| F-21 | 매칭 취소 (여행자) | 여행자는 코스 선택 전후, 여행 중에도 언제든 취소할 수 있다. 취소하면 칸이 비워진다 | 취소 200, 칸 즉시 반환, 메이트에게 알림. 취소 후 바로 다른 메이트에게 신청 가능 |
| F-22 | 메이트 취소 불가 | 메이트에게는 매칭 거절·취소 버튼이 없다. 문제가 생기면 언제든 차단(F-37, 사유 필수)으로 매칭을 끝내고, 필요하면 신고(F-36)한다 | 메이트의 취소 요청 403 |
| F-23 | 메이트 동시 매칭 상한 | 메이트 한 명이 동시에 진행할 수 있는 매칭은 최대 10건 | 10건이 차면 메이트 찾기 목록에서 자동 제외, 하나가 끝나면 다시 포함 |
| F-24 | 여행 기간 만료 자동 처리 | 여행 종료일이 지났는데 여행자가 여행 완료를 누르지 않은 매칭을 자동으로 끝낸다. ① 인증 50% 미만(코스를 고르지 않은 매칭 포함) → 자동 종료 ② 인증 50% 이상 → 자동 완료 | 매일 1회 일괄 처리, 칸 반환, 양쪽에 알림. ① 상태 EXPIRED ② 상태 COMPLETED + 앨범 자동 생성(F-33), 이후 상호 후기 작성 가능 |

### 3. 수익화 (MVP 제외, 발표에서 확장성으로 언급)

MVP는 여행자·메이트 모두 모든 기능을 무료로 쓴다. 매칭 칸도 무료 5칸이다.

| 확장 아이디어 | 내용 |
| --- | --- |
| 칸 추가 | 5칸을 넘는 동시 매칭, 장기 체류 여행자용 |
| 프리미엄 지도 | 인기 메이트의 테마 지도, 시즌 한정 지도 |
| 제휴 | 스팟(카페·가게) 제휴 쿠폰, 여행사·항공사 연계 |

### 4. 서비스 정책 요약

| 항목 | 값 |
| --- | --- |
| 지도 고르기 | 카드 1장 = 지도 1개. 공개 스팟 미리보기에서 고르면 바로 매칭 + 코스 확정 (메이트 수락 없음) |
| 목록 조건 | 메이트 성별·연령대(칩 복수 선택)로 거르기, 핀 개수 범위 필터 |
| 정렬 | 추천순(겹치는 취향 수, 기본) · 핀 적은 순 · 핀 많은 순 · 최근 업데이트 순 · 인기순(지도 선택 횟수) |
| 지도 공개 조건 | 스팟 5곳 이상 + 공개 스팟 정확히 2곳 |
| 매칭 전 공개 범위 | 지도 제목·캡션 + 공개 스팟 2곳. 나머지는 개수만 (자물쇠) |
| 채팅 열림 조건 | 코스 지도 스팟의 50%(내림) 인증 → 여행자가 열면 바로 열림 |
| 필요 인증 수 | floor(코스 스팟 수 × 0.5). 지도 선택 시 확정 (5곳 → 2, 7곳 → 3) |
| 방문 인증 | 사진·후기 + 업로드 순간 위치 1회 확인 (반경 200m), 좌표는 저장하지 않음 |
| 방문 기록 공개 | 인증 즉시 공개 · 메이트에게 알림 |
| 메이트 동시 매칭 상한 | 10건 |
| 여행자 매칭 칸 | 무료 5칸 (지도 1개 = 칸 1개) |
| 매칭 끊기 | 여행자·메이트 모두 언제든, 사유 선택, 칸 반환 |
| 지도 수정 잠금 | 여행 중인 여행자가 있으면 기존 스팟·지도 이름 수정 불가(새 스팟 추가만), 공개 스팟은 항상 수정 불가 |
