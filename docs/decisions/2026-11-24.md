### 11/24 결정 사항 (회의록 추가용)

**매칭**
- **메이트 찾기** (기존 "오늘의 추천 하루 3명"에서 변경): 조건을 통과한 메이트를 인원 제한 없이 목록으로 보여 주고 1명 선택
  - 정렬: 취향 일치순(기본) · 핀이 많은 지도 순 · 최근 업데이트 순 · 인기순 / 필터: 핀 개수 범위
  - 핀 개수는 지도 하나 기준
  - 하루 신청 횟수 제한 없음. 매칭 → 지도 확인 → 취소 → 다른 메이트 반복 가능 (일본인 여행자가 여러 지도를 볼 수 있게 하는 쪽을 선택)
- 목록 조건: 성별·연령대로 거르기. 연령대는 칩 복수 선택(20대 / 30대 / 40대 / 50대 이상) (후기 기반 정렬은 다음 단계)
- 선지도 후매칭 아님: 취향만 보고 매칭 → 매칭 후 지도별 캡션 + 공개 스팟 2곳 공개 → 마음에 드는 지도를 코스로 선택
- 공개 스팟 2곳은 메이트가 직접 지정, 코스 선택 시 그 지도의 스팟 전체 공개
- 매칭 칸: 무료 1칸, 유료로 칸 추가(칸당 과금, MVP는 화면만). 취소·종료·완료 시 칸 반환, 취소 후 바로 다른 메이트 신청 가능
- 여행자는 언제든 취소 가능 / 메이트는 거절·취소 불가
- 메이트 동시 매칭 상한 10명 (다 차면 목록에서 제외)
- 여행 종료일이 지났는데 코스 지도 인증이 50% 미만이면 매칭 자동 종료 (5곳 기준에서 변경)
- 인증 50% 이상인데 여행 완료(앨범 만들기)를 누르지 않았으면 종료일이 지난 뒤 자동 완료 (앨범 자동 생성, 후기 작성 가능)

**비밀지도·여행 중**
- 지도 공개 조건: 스팟 최소 5곳 + 공개 스팟 2곳 지정
- 방문 인증: 사진·후기 + 업로드 순간 위치 1회 확인(반경 200m), 위치 좌표는 저장하지 않음
- **방문 기록은 인증 즉시 메이트에게 공개·알림** (기존 "매일 12시 업데이트"에서 변경)
- 메이트 리액션·댓글 추가 (앨범에 들어감)

**채팅·안전**
- 채팅: 코스 지도 스팟의 50% 이상 인증 → 양쪽 수락 → 닉네임 쪽지형 + AI 자동 번역 (5곳 기준에서 변경)
  - 필요 인증 수 = 코스 스팟 수 × 0.5, 소수점 올림 (5곳 지도 → 3곳, 7곳 → 4곳). 코스 선택 시 확정
- 신고: 매칭 후 언제든, 프로필·방문 기록·댓글·채팅 어디서나
- 차단: 채팅이 열린 뒤 채팅창에서만 (여행자·메이트 모두), 차단 시 매칭 종료
- 만남 제안 기능 제외 (데이팅 앱 인상 방지)

**온보딩·기타**
- 국적 선택이 첫 화면 → 화면 언어와 이후 화면 분기 결정
- 여행 일정(방한 날짜) 입력 추가
- 메이트 설문은 "추천할 수 있는 취향·동네"
- 본인 인증(여권)은 MVP에서 화면만
- 여행 완료 후 상호 후기(별점·후기)
- AI: 메인 흐름은 자동 번역, AI 코스 추천은 홈의 별도 메뉴(선택 기능)
- 일본인 동행 찾기(일일 매칭)는 후순위: 화면과 발표 설명만

**기술 스택 (11/24 밤 확정안)**
- 앱: React Native + Expo (EAS Build, Expo Go 대신 개발용 빌드 사용)
- 백엔드: Supabase(로그인·사진 저장·DB) + Spring Boot(나머지 API 전부)
  - 앱은 DB에 직접 접근하지 않음 (모든 테이블 RLS 켜고 허용 정책 없음), 데이터는 Spring으로만
  - Spring은 Supabase 토큰을 JWKS로 검증, DB는 Session pooler 주소로 접속
- 지도: 네이버 지도 (`@mj-studio/react-native-naver-map`) + 장소 검색 API
- 로그인: 이메일 먼저 → 시간이 되면 카카오(한국인)·LINE(일본인)
- 비밀 키는 Spring 서버 환경변수에만, `.env`는 커밋 금지
