### 11/26 지도 SDK (Q-01, 잠정)

**상태:** 실기기 확인 전이라 확정이 아니다.

**선택:** 네이버 지도 `@mj-studio/react-native-naver-map` (11/24 결정 사항 유지)

**확인한 버전**
- Expo 58.0.26, React Native 0.88.1, React 19.3.0
- `@mj-studio/react-native-naver-map` 2.11.0 (네이버 지도 SDK 3.23.2)
- `expo-location` 58.0.22, `expo-build-properties` 58.0.12, `expo-dev-client` 58.0.21

**문서·코드로 확인한 것**
- Expo Go 불가, 개발용 빌드 필요. New Architecture 필요.
- Expo config plugin 지원. 네이버 Maven 저장소는 `expo-build-properties`로 추가한다.
- `NaverMapView`의 `locale` prop(`ko`, `ja`, `en`)이 네이티브 `setLocale`로 전달된다. 기본값은 기기 언어.
- 인증 실패 코드: 401(Client ID·패키지명 불일치), 429(서비스 미활성·한도 초과), 800(Client ID 없음).

**로컬에서 확인한 것**
- 앱 뼈대(PR #10) 위에서 타입 검사, `expo-doctor` 20/20, Android·iOS·웹 JS 번들 생성 통과.
- 린트는 앱에 설정이 없어 실행하지 않았다.
- config plugin 결과에 네이버 Client ID 메타데이터, Maven 저장소, 위치 권한이 들어간다.
- 검증 화면은 개발 빌드의 `/dev/map`(로그인 화면의 `[DEV] 지도 검증` 버튼)에서 연다.
- 네이버 지도는 웹을 지원하지 않아 웹에서는 안내 화면(`MapSpikeScreen.web.tsx`)을 보여 준다.

**남은 제약·미확인**
- 라이브러리 저장소는 React Native 0.85.1 기준으로 개발 중이다. 0.88.1에서의 네이티브 빌드는 확인하지 않았다.
- 안드로이드 실기기에서 지도, 핀 3개, 핀 선택, 현재 위치: 미확인.
- 일본어 지도 라벨이 실제로 보이는지: 미확인 (네이버 레퍼런스에 지원 언어 목록이 없었다).
- iOS: 미확인. 로컬에 CocoaPods가 없고 빌드를 시도하지 않았다.
- `react-native-maps`: npm 최신 버전(1.29.11)만 확인. 네이버 지도에 문제가 있을 때 비교한다.
- 패키지명·번들 ID `com.seoulmate.app`은 임시 값이다. 지도 콘솔 등록 전에 확정한다.

**개발용 빌드 전에 필요한 것**
1. 네이버 클라우드 콘솔에 앱 등록, Client ID 발급.
2. 로컬은 `app/.env`의 `EXPO_PUBLIC_NAVER_MAP_CLIENT_ID`에 넣는다.
3. EAS 빌드에는 `.env`가 올라가지 않으므로 EAS 환경변수(`development`)에도 등록한다.
4. Client ID는 네이티브 설정에 들어가므로 값을 바꾸면 다시 빌드한다.
